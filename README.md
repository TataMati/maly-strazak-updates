# Mały Strażak — aktualizacje zasobów

Publiczny kanał statycznych aktualizacji gry. Prywatny kod aplikacji nie jest tu publikowany.

Manifest: `manifest.json` (schema 1). Przy nowej paczce zmień `revision`, publikuj zasoby przed manifestem i podaj poprawne sumy SHA-256.

GitHub Pages powinno udostępniać `https://tatamati.github.io/maly-strazak-updates/manifest.json`.

Nie umieszczaj tu tokenów, kluczy podpisu ani prywatnych plików.
